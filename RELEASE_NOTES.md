OpenCAD is a from-scratch parametric 3D CAD application with a SOLIDWORKS-style workflow.

**Try it in the browser:** https://cad.greendealer.co.nz

## Downloads
- **Windows:** `OpenCAD-0.3.0-win-x64.exe` (installer)
- **macOS (Apple silicon and Intel):** `OpenCAD-0.3.0-mac-universal.dmg`

These builds are not code-signed yet:
- **Windows:** SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
- **macOS:** after dragging OpenCAD to Applications, right-click it and choose **Open** the first time. On macOS 15 and later, if it is still blocked, go to **System Settings → Privacy & Security** and click **Open Anyway**.

## What's in 0.3.0
- **Interface:** SOLIDWORKS-style menus, CommandManager, FeatureManager tree, PropertyManagers, confirmation corner, heads-up view toolbar, shortcut bar (S), mouse gestures, and right-click menus with context toolbars.
- **View:** SOLIDWORKS mouse and keyboard navigation, the 3D View Selector, the View Orientation flyout, display styles, and planes that look and behave like SOLIDWORKS (name in the plane, resize handles).
- **Sketching:**
  - Tools: line, centerline, midpoint line, five rectangle types, circle, perimeter circle, three arc types, straight and centerpoint slots, polygon, point, sketch fillet, trim.
  - Toolbar flyouts remember the last tool you used.
  - Snaps and inference lines, automatic relations, Smart Dimension, and under/fully/over-defined colouring.
- **Features:** extruded boss/cut, revolved boss/cut, fillet, chamfer, reference planes, sketch on faces, rollback, suppress.
- **Tools > Options:** the full System Options and Document Properties trees.
- **Files:** save/open, STEP and STL export, mass properties.
